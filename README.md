### What I've built

AES-256-GCM with PBKDF2 key derivation, share keys that travel in the URL hash so the server never sees them, a self-contained CLI decryptor for CI/CD, and a security section that says plainly what it does not protect. MIT licensed, live with real users before I took it down.
